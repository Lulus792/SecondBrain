## Übertragung auf SecondBrain

Die README beginnt mit Zweck, tatsächlichem App-Bild und Entwicklungsstatus.
Danach folgen Fähigkeiten, Paketbezug, eigener Build und Tastaturbedienung.
Lange Python-Anleitungen wurden nach STRUKTURPROTOTYP.md verschoben. Forschungs-
und Entwicklungsunterlagen bleiben erreichbar. Der CI-Badge führt zum echten
Workflow; er behauptet keine Freigabe für alle Geräte oder einen fertigen Release.
Eine eigene Projektlizenz bleibt eine offene Herausgeberentscheidung.

Die Texte sprechen Nutzer direkt an und nennen konkrete Handlungen. Eine abschließende
redaktionelle Prüfung des gesamten Endprodukts erfolgt erst vor 1.0. Entwicklungs-
nachweise und die gemeinsame Arbeit mit KI bleiben während der Entwicklung sichtbar.
